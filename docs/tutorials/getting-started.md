# 使用教程：从注册到出一份研报

> **读者**：拿到这个服务、手里只有一个浏览器的人。**不要求克隆仓库，不要求准备数据**。
>
> **本文数字来自一次真实使用**，但请把每一个数都当作**示例**而不是承诺：数据是滚动的，行情止于
> 导入当天、事件语料随日增量前移。本文写作时的数据边界：行情末端 **2026-09-30**，事件语料
> **2026-07-07 → 2026-10-08**（307,704 行）。你按下按钮时看到的日期与数字会不同，**结构与读法不变**。
>
> 如果你**已经克隆了仓库**：先照 README 的「快速开始」把基础设施、后端、前端都起起来（本教程
> 假定服务已在 `http://localhost:3001` 可用），另外两篇 [策略教程](ma_cross.md) 讲的是命令行复现，
> 与本篇互补。三篇的分工见文末。

## 0. 先认三个词

| 词 | 意思 |
|---|---|
| **PIT**（Point-in-Time） | 「那个时点当时能看到什么」。本项目的全部结论都锁在某个时点上：**只能用它之前已经公开的信息** |
| **`available_at`** | 一条信息**平台首次可用**的时刻。这是本项目设卡的唯一依据（不是事发时间） |
| **前视偏差** | 回测里偷看了未来。绝大多数「LLM + 量化」项目在这里翻车，PIT 就是防它的闸门 |

一篇教程能讲完的部分有限，但记住一条就够：**页面上凡是让你选「数据截止」「时点」的地方，都是在问「你要从哪一天的信息集出发」。**

## 1. 进来：注册与登录

打开服务地址，未登录会被送到登录页。点「注册」：

1. 填**邮箱**与**密码**——密码的规则不是「8 位以上」这么简单，而是 **8–72 个字节**。界面上写的是「至少 8 位」，但**一个汉字算 3 个字节**：24 个汉字就到上限了。超了会被拦下，提示原文是 `密码不得超过 72 个字节`。
2. 点**「注册并登录」**——注册成功即登录态，不需要再走一遍登录页。
3. 之后从这个浏览器进来会直接落在**研究首页**；「记住我」默认勾选，取消就要每次重登。

> 这是你自己的账号：自选股、回测记录、策略、模拟盘会话、研报**都只属于你**，别人访问同一台服务看不到你的东西。

## 2. 地图：你能去哪儿

页头九项，就是全部一级入口：

| 页头 | 干什么 |
|---|---|
| **首页** | 大盘总览（涨跌家数 / 涨跌停 / 成交额 / 板块）+ 快捷入口 |
| **对话** | 用自然语言问行情、查事件；回答带来源标注 |
| **回测** | 选策略与区间，出指标 / 净值 / K 线买卖点 / PIT 对比 |
| **策略** | 在线写自己的策略，跑之前先过前视静态检查 |
| **优化** | 参数网格扫描 + 批量回测 + 过拟合检验 |
| **因子** | 检验「新闻信号 / 价格动量」有没有截面预测力 |
| **模拟盘** | 纸上交易：策略出信号、你逐条裁决、按次日开盘价成交 |
| **深度研究** | 多 Agent 并行取证 → 多空对辩 → 出一份研报 |
| **个人空间** | 七个页签收纳你的一切产出 |

**两个容易找不到的东西先说**：

- **研报不在页头**。它是**模拟盘账户的产物**，入口跟着账户走——在模拟盘页点「出研报」（详见第 8 节）。
- **首页顶部有两个「截至」**，它们**通常不是同一天**：行情是**年度整片、按需刷新**（源侧什么时候放行新数据由它的质量门禁决定，实测有连停两个交易日的情况），事件语料则是**按自然日**增量、周末与假期也在出。两个日期不一样不是故障，是这两条数据通道各自的真实节奏。**鼠标悬停在那个日期上**会多一句「源侧止于 X」——用来分清是我们还没拉、还是源侧还没发。

## 3. 先问一句（对话页）

从首页点「对话」进来（页头第二项，地址是 `/chat`）。输入框写着 `问行情，查事件。例如「贵州茅台最近行情怎么样」`。空着的时候页面上有三张示例卡，随便点一张就能开工：

| 示例卡 | 它会做什么 |
|---|---|
| 行情 | 贵州茅台最近行情怎么样？ |
| 对比 | 对比宁德时代与招商银行近三个月的走势 |
| 事件 | 最近有哪些影响银行板块的新闻？ |

**怎么看回答**：

- 回答是**流式**出现的（一个字一个字往外走），过程中按钮从「发送」变成「停止」，点它可以中途停下。
- 回答里的**每一步工具调用都能展开**——折叠行写着 `工具调用 N 步`，展开能看到工具名、参数原文和返回值原文。**数据就是从这里来的**，不是模型编的。每一步前面有个状态符号：`⋯` 还没回来、`✔` 成功、`✕` 失败。
- 回答带**来源标注**（来源 / 原始来源 / 内容哈希三元组）。

**两个可能撞上的情况**：

- **网断了**：显示「已停止」，会话还在。留言停下没答完时，页面上会出现**「重新生成」**（说明文字：`上一次提问没有拿到回答。重发会在这个会话里再记一轮。`），点它重发同一问题，不用重新打字。
- **左栏是你的会话列表**，删一个会话要过一道内联二次确认（`删除这个会话？`）。

## 4. 加自选：把标的收进来看

进**个人空间 → 我的自选**。输入框支持**代码或名称**（边打边给候选），填完点「加自选」。

表格七列：`代码`、`加入价`、`最新价`、`加自选以来`、`加入时间`、`分组`、操作。「加自选以来」的起点是**加入时最近可得的有价收盘价**。

三条如实口径，界面上都写着：

- 取不到价的标的一律显示 **`—`**，**不编数**；鼠标停在「最新价」上会告诉你那个价是哪天的收盘。
- 名称查不到时提示原文：`没有匹配的标的（名称字典覆盖 96.7%）；也可以直接输入六位代码。`
- 已经在自选里的标的，提交按钮会直接变成「移出」——**判重是提交前就知道的**。

要分组：输入框里第二个格子填分组名（缺省进「默认分组」），之后可以在表格里用下拉把标的挪来挪去。分组名有约束：非空、≤24 字符、不含「/」；**「默认分组」不能改名也不能删**。

## 5. 写一个自己的策略（策略工作台）

进**策略**页。左栏两块：**我的策略**（你的）和**模板**（5 个现成的）：

| 模板 | 一句话 |
|---|---|
| 双均线交叉 | 快线上穿慢线金叉买入、下穿死叉卖出 |
| 事件驱动 | 利多事件（评分达标）触发买入，持有 N 个交易日后卖出 |
| 唐奇安通道突破 | 收盘创 N 日新高买入、跌破 N 日新低卖出 |
| RSI 超卖反转 | Wilder RSI 跌破阈值买入、回到高位卖出 |
| 放量突破 | 成交量放大且收阳时买入，持有 N 个交易日后卖出 |

**从模板开始**：点一个模板 → 它出现在编辑器里、**只读** → 点**「另存为我的」**（旁边写着 `保留这份源码，改成你的名字再保存（模板本身不动）。`）→ 改个名字 → 点底部的**「保存并运行」**把它存进你的库里。之后就可以随便改了。

> 「保存并运行」是**一步做完两件事**：先保存（这一步会跑静态检查），通过后立刻回测。想让检查单独跑，编辑器下方的检查面板在你改代码时会自己更新——**不必等到点保存**。

**编辑器下方是「检查结果」面板**，这就是本项目的护城河延伸到**你的代码**的地方。保存与运行之前，源码会被**只读地**分析一遍（不执行），拦下这些：

| 规则 | 拦什么 | 例子 |
|---|---|---|
| R0 | 语法错 | 少个括号 |
| R1 | 数据绕行 | `import duckdb`——绕过 `ctx` 自己读数据正是前视泄漏的入口 |
| R2 | 未来函数 | `.shift(-1)`、`.bfill()` |
| R3 | 越界索引 | `ctx.history[ctx.index + 1]`——history 物理上没有未来 |
| R4 | 声明与代码不符 | 声明 `USES_EVENTS = False` 却在读事件 |
| R5 | 入口形态 | 没有 `on_bar`、返回了单个 `Signal` 而不是列表 |

面板分两档：**error 会拦住运行**（`N 个 error 会拦住运行`，红色），warning 只提示（`N 个 warning：照跑，但建议看一眼`，琥珀色）。**每条都带行号，点一下跳到那一行**。

> **我们故意不给 pandas**。策略只能用 `math` / `statistics` / `itertools` / `functools` / `collections` / `dataclasses` / `typing` / `datetime` 这些纯计算库。`shift` / `bfill` 正是前视泄漏最常见的来源，不给它们，是产品立场不是疏漏。
>
> 写策略要用的行情与事件全部从 `ctx` 来：`ctx.history` 只看得到**当前 bar 及之前**，未来数据在物理上取不到。

**跑起来**：右下的运行条选标的与区间，点**「保存并运行」**（保存的是**库里那份源码**，运行的就是它），跑完自动跳到回测页。

## 6. 跑一次回测

进**回测**页。表单七项：策略、标的、起始日、结束日、模式、成本、参数。

- **策略**有「事件驱动」「双均线」，还可以选**你自己的策略**（在策略工作台里保存过的）。
- **区间留空**时后端按策略给缺省：事件驱动从**事件语料起点**开跑，其余策略从**首根 bar** 起。页面上写着这句。
- **模式**三选一：`PIT / 非 PIT 对比`（默认）、`仅 PIT`、`仅非 PIT`。
- **成本**默认开着：佣金与印花税 + 滑点（默认 5.0 bps，可调 0–100）。

点**「运行」**，页面出这些块：

| 块 | 看什么 |
|---|---|
| 指标卡 | 总收益 / 年化 / 最大回撤 / 夏普 / 胜率 / 交易次数 / 期末权益 |
| 净值曲线 | 策略 + 基准（+ 全市场等权，若报告含它） |
| K 线 | 买卖点标注，与交易明细逐条对应 |
| **PIT 与非 PIT 的差异** | 两口径对照表（仅事件驱动策略有，见下） |
| 交易明细 | 逐笔：入场 / 出场 / 持有 / 数量 / 收益 / 盈亏 / 出场原因 / 入场原因 |
| 未成交信号 | 信号发了但没成交的（一字涨停 / 停牌 / 资金不足），带原因 |
| 事件语料 | 窗口内该标的的全部事件，`事发` 与 `首次可用` **并列成列** |

**「PIT 与非 PIT 的差异」这块是最该看懂的**：

- **PIT** 只用当时已经公开的事件（`available_at` 早于当日 15:00）；**非 PIT** 改用事发时间，**等于允许使用尚未公开的信息**——它是故意穿越未来的对照组。
- 顶部那行是核心量化值：**期末权益差异（非 PIT 相对 PIT）**。
- **差异方向不预设**：看到未来**不等于**赚得更多。入场日不同，孰优孰劣取决于样本；本次可能是正的，下次可能是负的。
- 选「双均线」时这块会告诉你：`双均线不消费事件语料，两种模式必然得到同一份结果，因此不做无意义的二次回测。要看这个对比，请选事件驱动策略。`——**这不是报错**。

**几个如实提示**（报告与页面上都会出现，不是装饰）：

- 区间太短（不足 120 个交易日）时会常驻一句：年化与夏普按 252 折算会**放大噪声**。
- 基准口径是**全市场等权组合代理**（数据源不覆盖指数），报告里会自述这一点。
- 「未成交信号」是真实存在的：A 股一字涨停你买不进、一字跌停你卖不出，引擎如实记录而不是假装成交。

## 7. 扫一遍参数（优化页）

进**优化**页，两个页签：**参数网格** 与 **批量回测**。

**参数网格**：定策略 + 标的 + **最多 2 条参数轴**（比如 `fast = 3, 5, 8`），点「运行」。页面**逐格推送进度**（`已完成 N / M 格`），跑完给你：

- **全网格夏普分布**（`红点是被选中的那一格`）
- **参数网格热力图**（红正蓝负，对称于 0）——**带表格视图孪生**（点「看表格」），色盲或打印场景用得上
- **过拟合检验（DSR）** 卡

**DSR 是什么，为什么它在这页最中间**：你从 25 组参数里挑出夏普最高的那组，这个**挑选动作本身**就会造出假信号——挑出来的 0.3 夏普，可能只是运气。DSR 回答的是「观测到的夏普在 N 组参数里**不是运气的概率**」，常用显著线画在 0.95。卡片上还会列出输入清单（试验数 N、最优夏普、期望最大 SR₀、偏度、峰度、观测数）。

> 跑不出 DSR 时它会**如实说原因**（比如「有效试验不足 2 组」），下面还有一句 `原因以服务端给出的为准——本页不自己编一句。` 本项目不接受用一句「不适用」糊过去。

**点热力图上任意一格可以重跑那一格**（不重跑整个网格）。

**批量回测**：多个标的 × 多条策略，每个组合一格，出汇总表。

## 8. 纸上交易（模拟盘）

进**模拟盘**页。**这一页的主人是账户，不是表单**——第一次进来是一张建会话的表单，建好之后这页就变样（表单收进右上角的「＋ 新建会话」）：

| 字段 | 说明 |
|---|---|
| 会话名 | 随便起 |
| 初始资金（元） | 默认 500,000 |
| 标的池 | **1–20 只**，六位代码，空格或逗号分隔 |
| 策略 | 内置两个，或「我的策略」（**必须是已保存的**——模拟盘只认库里的源码） |
| 起点 / 区间终点 | 终点留空 = 用本地行情末端 |
| 成本 | 佣金 + 印花税、滑点 5bps，默认都开 |

**池子里每只标的拿等额额度**（初始资金 ÷ 只数）。

建好之后，页面顺序就是这件事的顺序：

### 8.1 决策闸门——这一页唯一「等你动手」的地方

策略每天收盘后生成决策，等你裁决。**两条口径是这个功能最容易被误解的地方，界面上写在按钮旁边**：

1. **批准 ≠ 成交**。批准只改状态；**成交发生在下一交易日的开盘**——批的这一刻，成交价还不存在。
2. 批完还要**点一次「推进一天」**才会成交。

所以你会看到两种卡片：**待审批**（实心，等你动手）和**已批准（待次日开盘成交）**（描边，你已决定、等市场）。卡片上写着「预计买/卖多少股 · 按决策日收盘价约多少元」——**这是估算**；真正的股数与价格在次日开盘时才算出来，成交后卡片上会多一行**实际成交**。

**六态**（决策流水里每条都挂着）：

| 状态 | 含义 |
|---|---|
| 待审批 | T 日收盘生成，等你裁决 |
| 已批准（待次日开盘成交） | 你批了，还没到成交时点 |
| 已成交 | 成交了，股数与价格已确定 |
| 已驳回 | 你驳回了 |
| 未审批过期（未审批不成交） | 你没理它，过期作废——**批准才可能成交，不批一定不成交** |
| 已批准未成交 | 批了但市场没给机会（一字板 / 停牌 / 资金不足） |

**推进控制**：「推进一天」走一个交易日；「跑到结束」一路推到区间末端（**不可逆**，所以要过一道内联二次确认，旁边选新决策是「全部批准」还是「全部驳回」）。每次推进后会列一行回执：`成交 N 笔` / `未审批过期 N 笔` / `新生成 N 条待审批`。

**这是模拟盘而不是实时盘**：会话只能回放到**本地行情末端**，界面上写着"数据到哪模拟到哪"。你选的起点是过去的某一天，不是今天。

> **一个可以验证的承诺**：全部批准的会话，**成交逐笔等于一次回测**。撮合、费用、A 股规则（一字板拒单、停牌顺延）与回测引擎是同一套代码，不是两套。

### 8.2 账户与曲线

账户卡上是**净值**（英雄数字）、初始资金、总收益，加三个陪读数：可用现金 / 持仓市值 / 已实现盈亏。下面是净值曲线（**▲ 买入、▼ 卖出标在成交日**）、持仓表、决策流水、每日结算。

## 9. 出一份研报，分享出去

在模拟盘页、账户卡下面有一个按钮：**「出研报」**。旁边写着它是什么：

> 绩效研报：指标 / 归因 / 逐笔复盘（含教训）/ 证据链，可分享给未登录的人看

点了之后跳到研报页。研报里有：

- **指标卡 / 归因表**
- **逐笔复盘**：每个回合的收益 vs 同期全市场等权、超额，以及买入/卖出理由；已了结的回合还会带一条**教训**
- **证据追溯**：正文里每个数字都能点开看它的来源事件（双时间戳 + 来源三元组）。页脚有一句：`本报告由 QuantSage 生成，仅供研究用途，不构成投资建议。`
- **如实标注**：口径与边界逐条列出（未平仓不结算、区间太短年化会放大、证据被平台修订过、证据在本地语料查无此行等），没有要说的就写「本次没有需要额外说明的口径问题」

**三个动作**：

| 动作 | 结果 |
|---|---|
| **生成分享链接** | 出一个链接，**未登录的人也能打开**（只读）。可以「撤销分享」——撤销后旧链接立刻失效 |
| **导出 PDF** | **服务端渲染**，与屏幕上逐像素同款，**不弹打印对话框** |
| **导出 Markdown** / **打印** | 另有这两个出口 |

> **同一批数据不会重算**：如果这个账户在同一状态下已经出过报告，再点「出研报」会直接打开那一份，并如实告诉你 `这批数据已有报告，打开的就是那一份（未重算、未再调用模型）`。

## 10. 深度研究：看着多 Agent 跑完

进**深度研究**页。一个输入框写明问题（默认填着 `分析一下贵州茅台现在值不值得买`），可选填标的与**数据截止**——这个日期决定这次研究**看得到哪些信息**（取证一律按 `available_at ≤ 时点` 过滤，留空取行情末端）。「路径」默认「自动判定（推荐）」：系统先判这问题该走对话还是走深研。

点**「开始研究」**，原地就能看着它跑：

- **执行阶段**（横向十段）：行情技术面 / 新闻事件 / 基本面事件 / 政策面 / 因子量化 → 证据归并 → 多方 / 空方 → 综合撰写 → 风控闸门。每段有状态（未开始 / 进行中 / 降级 / 待审批）与耗时。
- **并行瀑布**：一行一次节点执行，**条长就是真实耗时**。取证五条是并行跑的，所以你会看到几条横着叠在一起、长短不一——**检索那条通常最长**（本地精排是串行的，不把它画短）。
- **预算**：四个计量条（调用次数 / token / 成本 / 用时），到限会标「已超限」。
- **阶段带/瀑布看不够细**时，底下有「事件时间线」可展开，逐条是原始节点事件。

**跑到需要你拍板时，会停下来给你一张审批卡**（这也是这个产品的设计立场：**合规判断由代码做，不由模型做**）：

| 卡片 | 什么时候出现 | 你的选项 |
|---|---|---|
| **措辞需要你确认** | 报告正文里出现了绝对化表述或买卖指令 | 「继续」（你知道并接受） / 「放弃这段」 |
| **预算已到上限** | token / 时间 / 成本任一超限 | 「加预算继续」 / 「用现有结果收尾」 |

卡片上可以留一句备注，会记进这次运行。**断线也不怕**：这张卡在运行页上重新进来还在（状态从服务端真源恢复），选完继续跑。

跑完点「看这份研报」——**产物接的是同一套研报容器**：分享、导出 PDF、证据链全部可用，与第 9 节完全一样。

> 关于时间：**冷启动首问比预热慢得多**（本地检索模型要加载）。这是已知边界，PRD 的口径是「冷启动首问 ≤ 60s、预热 ≤ 30s」，不假装更快。

## 11. 事后回看：个人空间

**个人空间**七个页签：

| 页签 | 内容 |
|---|---|
| 我的自选 | 见第 4 节 |
| 我的回测 | 每次回测落库；点「重开」载入完整报告并回填表单 |
| 会话历史 | 点「打开」回到那次对话 |
| 我的策略 | 你的策略列表；点「去工作台」继续编辑 |
| 我的优化 | 网格 / 批量的汇总，**点一条重开（不重跑）** |
| 我的模拟盘 | 你的会话列表 |
| 深度研究 | 你的运行记录，点进运行页可**续看 / 审批** |

**决策反思在哪**：在**研报**的「逐笔复盘」里——一个回合**到期结算之后**才会生成长教训，没到期就写 `还没有结果可总结——到期后才有教训。` 这不是缺数据，是**如实不编**。

## 12. 六个容易读错的地方

1. **「年化」在短区间会失真**。不足 120 个交易日时报告与页面都会提示；55 天的窗口，年化是按 252 日**外推**出来的，量级仅供参考。
2. **`—` 不是 0**。取不到数的地方一律留空，**不补零**。补零会让「没有数据」和「数据是 0」混淆。
3. **非 PIT 的收益可能更低**。「看到未来」不保证「赚得更多」，两口径只在入场时点上有差别。
4. **基准不是沪深 300**。数据源不覆盖指数，用的是**全市场等权组合代理**，报告里自述口径。
5. **模拟盘的「批准」只是一个状态**。成交在次日开盘，批完要点「推进一天」。
6. **研报不在页头**。它是账户的产物，入口在模拟盘页。
